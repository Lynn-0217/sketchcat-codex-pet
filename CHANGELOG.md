# Changelog

All notable changes to Sketchcat are recorded here.

## 1.1.0 — 2026-09-24

- Refined the cat into a cuter, shorter, rounder silhouette while preserving the minimalist 2D line-art style.
- Softened the upright ear shape and added a tiny smile with subtle peach cheeks.
- Rebuilt all nine standard animation rows and all sixteen look directions around one consistent design.
- Preserved the no-legs rule, whole-body shortening for downward looks, and upright ears in the failed animation.
- Removed the initial size pop from the jumping transition.
- Revalidated the 8 × 11 Codex v2 atlas and refreshed all preview assets.

## 1.0.0 — 2026-07-21

- Initial public-ready Codex v2 package.
- Added all nine standard animation rows.
- Added sixteen clockwise look directions.
- Made down-looking poses progressively shorter.
- Removed separate legs from directional running frames.
- Kept both ears upright throughout the failed animation.
- Smoothed the idle-to-jumping hover transition.
- Added installation, preview, validation, and licensing documentation.
